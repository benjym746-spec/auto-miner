# Auto Miner (Meteor Client addon)

Set two corners with `.miner pos1` and `.miner pos2`, then `.miner start`.
Built for Minecraft 26.3 with Meteor Client 26.3 (see gradle/libs.versions.toml).

Every push builds the jar automatically (GitHub Actions). Download it from the
repo's Releases page (or the Actions run's artifacts) and put it in your mods
folder next to Meteor Client.
